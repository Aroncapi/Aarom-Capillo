## 🚀 Proyectos Destacados (GitHub Pinned)

### 🔹 1. [CONSEGO — Sistema Distribuido de Control de Solicitudes de Acceso](https://github.com/Aroncapi/CONSEGO-MICROSERVICIOS)
- **Tech Stack:** Java 17, Spring Boot, Spring Cloud (Eureka, Gateway), Angular 17, Docker, Kubernetes, MySQL, MongoDB, RabbitMQ.
- **Detalles:** Arquitectura de microservicios con enrutamiento centralizado en API Gateway, comunicación síncrona mediante OpenFeign + Resilience4J (Circuit Breaker) y auditoría asíncrona basada en eventos con RabbitMQ y persistencia políglota.

### 🔹 2. [Biblioteca Escolar — Sistema Integral de Gestión](https://github.com/Aroncapi/Biblioteca)
- **Tech Stack:** Java 21, Spring Boot 3.2.3, Spring Security (JWT), Spring Data JPA, Flyway, MySQL, Angular 21, Chart.js, Swagger/OpenAPI.
- **Detalles:** Plataforma Full Stack con documentación de API REST vía Swagger, migraciones de base de datos automatizadas con Flyway, generación de reportes (PDF/Excel) y testing automatizado con JUnit y cobertura JaCoCo.

### 🔹 3. [Clínica Jesús — Sistema de Gestión de Citas](https://github.com/Aroncapi/ClinicaJesus)
- **Tech Stack:** Java 21, Spring Boot, Spring Cloud (Eureka), MySQL (database-per-service), Angular 20, JWT, SMTP.
- **Detalles:** Sistema modular en microservicios desacoplados (`auth`, `doctor`, `schedule`, `appointment`, `payment`, `notification`) con descubrimiento dinámico de servicios y control de accesos por roles.

### 🔹 4. [Elixir Cocktails — Velvet & Gilt](https://github.com/Aroncapi/Elixir-Cocktails)
- **Tech Stack:** Java 25, Spring Boot, Spring Cloud, Angular 22, MySQL 8 (Flyway), Docker Compose, Nginx.
- **Detalles:** Plataforma de cotización y servicios con seguridad avanzada (rate limiting, tokens internos inter-servicios, validación por magic bytes) y orquestación completa con Docker Compose.

### 🔹 5. [Licorix — Tienda de Licores](https://github.com/Aroncapi/Licorix)
- **Tech Stack:** C# (.NET Core 8 MVC), Razor Views, SQL Server, ADO.NET, API REST.
- **Detalles:** Plataforma E-commerce bajo el patrón MVC con 26 procedimientos almacenados en SQL Server, funciones de integridad (`fn_EsAdministrador`), triggers y control de historial de precios.

### 🔹 6. [Easy-Chef — App Móvil Android](https://github.com/Aroncapi/Easy-Chef)
- **Tech Stack:** Kotlin, Jetpack Compose, Material 3, Firebase, Room, Retrofit, Google Maps API, ExoPlayer.
- **Detalles:** App nativa con interfaz declarativa moderna, persistencia local offline (Room), consumo de APIs públicas (TheMealDB / TheCocktailDB) y mapa interactivo de restaurantes.
